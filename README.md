# Telegram конкурс-бот / Giveaway Bot

Функции:

- `/start` — приветствие, условия и кнопки участия.
- Проверка подписки на канал.
- Сохранение участников в SQLite.
- Админка `/admin`: статистика, выгрузка CSV, рассылка всем участникам, выдача сообщения победителю/сегменту.
- Очередная рассылка с задержкой и отчетом.
- Премиум-оформление: обычные emoji, optional `custom_emoji_id`, стили кнопок `primary/success/danger` через raw Telegram Bot API payload.

## Быстрый старт

```bash
python -m venv .venv
.venv\Scripts\activate   # Windows
pip install -r requirements.txt
copy .env.example .env
# заполнить BOT_TOKEN, ADMIN_IDS, REQUIRED_CHANNEL
python -m app.main
```

## Важно

1. Бот может писать рассылку только пользователям, которые сами нажали `/start`.
2. Для проверки подписки бот должен иметь права в канале или канал должен позволять проверку участников.
3. Цветные кнопки и custom emoji зависят от актуального Telegram Bot API и клиента пользователя. Если библиотека не поддерживает новые поля, проект отправляет такие сообщения raw-запросом.
4. Тексты рассылок редактируются админом внутри `/admin`. По умолчанию шаблоны нейтральные и не обещают приз тем, кто не выбран победителем.

## Команды

- `/start` — пользовательский вход.
- `/admin` — панель администратора.

## Админ-настройки

В `/admin` появилась кнопка `⚙️ Настройки`. Через нее можно менять без перезапуска:

- канал для обязательной подписки: `@channel` или `-100...`;
- публичную ссылку кнопки подписки;
- контакт администратора для кнопок получения приза;
- задержку между сообщениями в рассылке;
- ID premium/custom emoji.

Настройки сохраняются в SQLite-таблицу `settings`; значения из `.env` используются как стартовые дефолты.


## Сценарий по ТЗ

Пользовательский поток теперь повторяет пример:

1. `/start` показывает `🔒 Требуется подписка на каналы`, канал и две кнопки.
2. Кнопка подписки ведет на заданный канал.
3. После `✅ Проверить подписку`, если пользователь подписан, бот сразу отправляет текст выигрыша и кнопку `связаться`.
4. Текст выигрыша, второй рассылочный текст, контакт и канал меняются в `/admin → ⚙️ Настройки`.


## Авто-победа через время

После успешной проверки подписки бот показывает регистрацию, а затем через время из `/admin → ⚙️ Настройки → ⏳ Время до авто-победы` автоматически отправляет сообщение победителя. Контакт куратора задается в настройках и подставляется в шаблон как `{contact}`.
